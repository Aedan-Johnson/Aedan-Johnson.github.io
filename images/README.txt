DRAG AND DROP YOUR PHOTOS INTO THIS FOLDER.

Just save your photo with the matching name below and it shows up on the
site automatically, no code editing needed.

  profile.jpg   your photo, shown in the sidebar on every page
  photo-2.jpg   SkillsUSA
  photo-5.jpg   bench / hardware work
  photo-6.jpg   Scouts

(cyberpatriot-18.png is already here, that slot is done.)

Tips:
  - JPG or PNG both work.
  - Any size is fine, but if your photos are huge (multiple MB, straight off
    a phone), the pages will load slower. Around 1200px wide is plenty.
  - Keep the filenames exactly as spelled above (all lowercase, with the
    dash), or the photo won't show up.

Want to use different names instead? You'd need to open photos.html and
change the file names in the "src" and "data-full" spots, and the profile
img src at the top of each page.
